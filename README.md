# 🧁 My First Cupcake Recipe Site!

Welcome to my very first web project! This is a minimalist recipe page built using raw HTML and a single image. 

### Behind the Scenes (Plot Twist!)
Full disclosure: I originally built this site using a completely fake recipe just to test the HTML tags and make the page look engaging. But thanks to some quick troubleshooting, the code is now fixed, the cupcake image finally loads, and it has been updated with a **100% real, fully bakeable blueberry cupcake recipe**!

### What's inside:
* An actual, working recipe for fluffy blueberry cupcakes.
* A picture of a cupcake (`cupcake.jpg`) that now displays perfectly.
