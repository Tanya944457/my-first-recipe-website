# 🧁 My First Cupcake Recipe Site!

Welcome to my very first web project! This is a minimalist recipe page built using raw HTML and a single image. 

### Behind the Scenes (Plot Twist!)
Full disclosure: I built this site using a completely fake recipe just to test the HTML tags and make the page look engaging. 

### What's inside:
* A fake recipe of blueberry cupcakes filled with humour.
* A picture of a cupcake (`cupcake.jpg`) that now displays perfectly.
